# Agent Template Weekly Upstream Apply

Use this project's template repository and the configured learning repository.
Read the installed `update-agents-file-templates` skill and the consolidation
skill's `references/integration.md` and mandatory `references/coherence.md`. Use Python with PyYAML available; on the
managed local host, `uv run --with PyYAML==6.0.3 python` provides that runtime.

1. Inspect every pending handoff under `.work/learning-upstream/`, including
   previously approved and applied drafts. Resolve source-note identity,
   current template IDs, actual source coverage and review authority.
2. Review unapproved drafts under configured delegated technical instruction
   authority. Promote clear reusable privacy-clean rules, reject non-reusable
   material, and retain actual choices or missing evidence with a concrete
   next action. Record the authority and decision per draft. A clean draft
   alone is not approved, and skipping review is not a resolved outcome.
3. Prepare the reviewed full-source replacement and a hash-bound `--edit-plan`
   for each novel rule; apply the proportional council from the coherence
   contract. Assess cumulative repetition, conflicts and loaded-context cost.
   Preview and apply approved clean drafts using the owning helper's
   `--apply-learning-draft` mode, with `--apply` only after inspecting the
   preview. For applied drafts verify current coverage instead of duplicating
   rules. Reconcile status to applied after downstream verification.
4. Discover affected generated instructions in configured scan roots. Refresh
   their managed blocks with the owning generator, preserving local sections,
   placeholder values and concurrent work. Save before/after hashes and verify
   each output with the generator's check mode. Unavailable roots, unresolved
   overlap or a stale consumer leave distribution pending.
5. Validate changed Markdown and Python; run the privacy scanner and template
   workflow tests. When skills change, reconcile their complete eligible folders
   into the shared collection and every configured installation, preserving local
   config and explicitly recording intentional overrides.
6. Build integration manifests for affected archived note IDs, including source
   rule coverage, complete skill-copy parity and current template consumers.
   Run the learning helper's `integration-check`, `integration-record` and
   scoped `integration-audit --require-verified`. Audit older verified receipts
   for drift too. Keep the original historical note intact; the state index
   records the current integration and promotion outcome.
7. Refresh the upstream summary and out-of-sync report. Report reviewed/applied
   drafts, refreshed consumers, source/install parity, receipt paths, validation
   and each residual blocker. Only current receipt verification permits an
   integrated result; draft creation, template apply and a report alone do not.

Use the existing source-repository and learning-helper commands; do not stage,
commit, push, open pull requests, publish or change unrelated project content.
